# WolfClip

**История буфера обмена для macOS и Linux — тот самый Win+V, которого не хватало.**

Нажми одно сочетание в любом приложении, выбери что-то из скопированного раньше, и оно вставится туда, где ты печатаешь.

## Зачем WolfClip

- **Вставка сразу.** Выбрал запись, и WolfClip вставил её в приложение, где ты был. Никаких лишних нажатий.
- **Всё, что копируешь.** Текст, ссылки, цвета, код, картинки и файлы, каждое в понятном виде. У `#4F8CFF` образец цвета, у скриншота миниатюра, у кода моноширинный шрифт.
- **Находится за секунду.** Начни печатать, и запустится поиск. `Tab` переключает фильтры, `⌘1`–`⌘9` вставляют одну из первых девяти записей.
- **Закрепы не пропадают.** Адреса, шаблоны и сниппеты держатся сверху и никогда не вытесняются.
- **Удобно с клавиатуры и мышью.** Стрелки, Enter, Esc, а ещё клики, кнопки при наведении и контекстное меню.
- **Приватно по умолчанию.** Пароли из менеджеров паролей не записываются. История хранится только на твоём компьютере.
- **Нативно и легко.** Swift и SwiftUI на macOS, GTK 4 на Linux. Без Electron, в простое процессор почти не нагружается.
- **Тёмная, светлая или как в системе.** Говорит по-русски и по-английски, язык берёт из системы.

## Установка

### macOS

1. Скачай **WolfClip-macOS.zip** из [последнего релиза](https://github.com/RakushkaTOP/wolfclip/releases/latest) и перетащи **WolfClip** в **Программы**.
2. Открой его. Приложение не нотаризовано Apple, поэтому при первом запуске macOS попросит подтверждения. Зайди в **Системные настройки → Конфиденциальность и безопасность** и нажми **Всё равно открыть**, или выполни:
   ```bash
   xattr -dr com.apple.quarantine /Applications/WolfClip.app
   ```
3. Разреши **Универсальный доступ**, когда WolfClip попросит. Он нужен, чтобы приложение само нажимало `⌘V` и открывалось у текстового курсора. Без него выбранное только копируется.

WolfClip живёт в строке меню и запускается вместе с системой. Жми **⇧⌘V** где угодно.

<details>
<summary>Сборка из исходников</summary>

Нужны только Command Line Tools от Xcode:

```bash
git clone https://github.com/RakushkaTOP/wolfclip.git
cd wolfclip/macos
./build.sh install          # arm64; UNIVERSAL=1 ./build.sh install — сразу для Intel и Apple silicon
```

</details>

### Linux

```bash
curl -L https://github.com/RakushkaTOP/wolfclip/releases/latest/download/wolfclip-linux.tar.gz | tar xz
cd wolfclip-linux && ./install.sh
```

Установщик проверит Python 3 с GTK 4. Если чего-то нет, он предложит поставить это через `apt`, `dnf`, `pacman` или `zypper`. Всё остальное ставится в домашнюю папку. Удалить: `./uninstall.sh` (с `--purge` удалится и история).

Жми **Super+V** в любом приложении.

| Сессия | Горячая клавиша | Автовставка | Где открывается |
|---|---|---|---|
| **X11** | Встроена (Super+V, меняется в настройках) | Встроена | У указателя мыши |
| **Wayland** (бета) | Назначь `wolfclip --toggle` в настройках системы (для GNOME в настройках есть кнопка) | Через [`wtype`](https://github.com/atx/wtype) или [`ydotool`](https://github.com/ReimuNotMoe/ydotool) | Решает композитор |

Проверенная конфигурация — X11. На Wayland WolfClip работает через XWayland, чтобы следить за буфером, и насколько это получится, зависит от композитора. Буду рад отчётам.

## Горячие клавиши

| | macOS | Linux |
|---|---|---|
| Открыть историю | `⇧⌘V` | `Super+V` |
| Выбрать | `↑` `↓` | `↑` `↓` |
| Вставить | `↵` или клик | `Enter` или клик |
| Вставить без форматирования | `⇧↵` | `Shift+Enter` |
| Вставить запись 1–9 | `⌘1`–`⌘9` | `Ctrl+1`–`Ctrl+9` |
| Только скопировать | `⌘C` | `Ctrl+C` |
| Закрепить / открепить | `⌘P` | `Ctrl+P` |
| Удалить | `⌘⌫` | `Ctrl+Delete` |
| Следующий / предыдущий фильтр | `Tab` / `⇧Tab` | `Tab` / `Shift+Tab` |
| Очистить поиск, закрыть | `Esc` | `Esc` |

Сочетание меняется в настройках. На macOS `⇧⌘V` перехватывает «Вставить и сохранить стиль» в программах, где оно есть. Если пользуешься им, выбери `⌥⌘V` или другой вариант.

## Приватность

- Записи, которые менеджеры паролей помечают как секретные, пропускаются: на macOS это пометки `org.nspasteboard` (concealed и transient), на Linux — подсказка менеджера паролей KDE.
- История — это локальный файл: `~/Library/Application Support/WolfClip` на macOS, `~/.local/share/wolfclip` на Linux. Никуда не отправляется.
- Запись можно в любой момент поставить на паузу из меню.

## Как это устроено

<details>
<summary>Для любопытных</summary>

**macOS.** Приложение в строке меню на Swift и SwiftUI. Несколько раз в секунду сверяет счётчик изменений буфера, это практически бесплатно. Горячая клавиша — Carbon hot key, ей не нужны разрешения. История открывается в неактивирующей панели: она забирает клавиатуру, но не фокус твоего приложения, поэтому вставка уходит обратно туда, где ты был. Вставка — синтетический `⌘V`. Окно ставится у текстового курсора через Accessibility API, а если курсор не найден — у мыши.

**Linux.** Python 3 и GTK 4, без дополнительных Python-пакетов. Изменения буфера приходят от GTK. Горячая клавиша, фокус и автовставка работают напрямую с X11 (`XGrabKey`, EWMH, XTest) через `ctypes`. В терминалы автоматически уходит `Ctrl+Shift+V`. В [`linux/test`](linux/test) лежит Docker-стенд, который запускает приложение без экрана на Xvfb для тестов.

</details>
